# Gear Catalog Data Audit

Generated by scanning `app/data/catalog/*.json` (the data behind the Gear page and character
builder shop tabs) for fields that are blank/null for that item's type. This is a checklist, not
a final verdict -- some blanks are intentional (e.g. a null Concealability on an item the book
doesn't rate for concealability). Fill in what you have from the books, strike through anything
that's correctly N/A, and leave the rest for later.

Each row cites the sourcebook abbreviation and page already recorded in the catalog, so you know
which book to open. Abbreviations in use: **SR2** = SR2 core, **SSC** = Street Samurai Catalog,
**FOF** = Fields of Fire, **BSW** = Boston Shadowrunners' (or similar fan) weapon compendium,
**RIG2** = Rigger 2, **RG** = Running Gear (fan), **SHADOW** = Shadowtech, **CYB** = Cybertechnology.
