Shadowrun 2nd Edition — Matrix Quick Reference

Virtual Realities 2.0 · TN = target number · never below 2

The Deck & Your Pools

Deck: MPCP / Bod / Evasion / Masking / Sensor. No persona program above MPCP; the four together ≤ MPCP × 3. Utilities cap at MPCP.

Bod resists icon damage · Evasion combat maneuvers, part of Trace Factor · Masking hides you (Detection Factor) · Sensor spots IC, resists maneuvers.

Hacking Pool = (Intelligence + MPCP) ÷ 3, round down. Refreshes like other dice pools. Adds to System, attack, defense, maneuver and attribute tests. Not to Initiative, to Body/Willpower vs gray or black IC, or to doctrinal rolls.

Detection Factor (DF) = (Masking + Sleaze) ÷ 2, round up. No Sleaze running: Masking ÷ 2, round up. Each suppressed IC costs 1 DF (minimum 1).

Actions

Free: speak a word · delay · buffer a message (100 words) · stop an up/download · unload a program · release suppressed IC · suspend/restore icon · Reality Filter on/off (next turn) · Analyze IC/Icon · Retrain.

Simple: attack · combat maneuver · improvised attack · Swap Memory · Analyze Security / Subsystem · Download, Upload, Edit File · Decrypt Access/File/Slave · Crash Application · Relocate · Monitor Slave · Scan Icon.

Complex: every Logon · Graceful Logoff · Null Operation · every Locate · Analyze Host · Crash Host · Decoy · Disinfect · Validate / Invalidate Passcode · Dump Log · Redirect Datatrail · Control / Edit Slave · comcalls · Medic · change deck mode.

Non-combat runs: actions per turn = Reaction ÷ 10 (round up) + 1 per Initiative die beyond the first. Each action = 1 Complex or 2 Simple (a Free can replace a Simple).

Subsystems: Access (logons) · Control (host-wide) · Index (finding things) · Files (data) · Slave (devices). Passive alert: all +2.

Ongoing (up/download, Locate Paydata): seconds ÷ 3 = Combat Turns. Monitored (Control/Edit/Monitor Slave, comcalls): spend a Free Action every action or it aborts.

Tally, Alerts & Trace

The tally crossing a trigger step fires that step's IC and alert changes (several at once if it jumps past several).

No alert → reactive/trace IC. Passive → proactive white/gray IC, subsystems +2. Active → black IC, security deckers, shutdown.

Trace IC: Hunt cycle — attacks vs Trace Factor until it hits; you can fight it. Location cycle — 10 ÷ its successes turns, then your jackpoint is found (proactive IC −1 TN to hit you; +1 to every later tally increase; security dispatched). Beat it: crash it while hunting; Relocate (Simple, Control Test) spoofs one trace for a turn; Graceful Logoff (+trace rating to TN). Jacking out leaves 1D6 turns on the clock.

Trace Factor = Evasion − Trace IC rating + Camo + redirects left + jackpoint and bandwidth modifiers.

Cybercombat

Attack any icon that is visible (it attacked you, spoke, or showed itself) or located (Analyze / Locate IC, Locate Decker). Every attack is a Simple Action.

  1. Attack Test: decker rolls utility Rating + Hacking Pool; IC rolls Security Value. TN from the table below, by the target's status.
  2. Damage Code: decker's Attack = Rating / level coded into it (L/M/S/D). IC = IC Rating / level by host code. +1 level per 2 attack successes.
  3. Resist: Bod dice (IC: Security Value) vs Power; Armor utility lowers Power. −1 level per 2 successes. Shield successes come off the attacker's.

Icon damage: L 1 box · M 2 · S 3 · D 6. Ten boxes and the icon crashes; a persona crash dumps you. Wound modifiers by total boxes: 1–2 L, 3–5 M, 6–9 S.

Improvised attack (Simple): move points out of Evasion and/or Bod as Power (≤ MPCP) for this action; Computer Test vs Power: 1 success L, 2 M, 3 S, 4+ D.

Maneuvers (Simple)

Opposed: you roll Evasion vs their Sensor (Cloak lowers your TN); they roll Sensor vs your Evasion (their Lock-On lowers theirs). IC rolls Security Value both ways. Ties go to the defender.

Evade Detection: you vanish from them for net-success turns (each tally increase cuts 1). Not vs reactive IC in its location cycle.

Parry: +net successes to their TN to hit you, until their next attack.

Position: −net to your next attack's TN, or +net to its Power. Lose and they get the bonus.

Getting Out

Simsense overload (hot deck, icon hit by white/gray IC): Willpower vs L 2 / M 3 / S 5; fail = 1 Stun box. DNI-only +2, ICCM −2. Cool decks and tortoises immune.

Dump shock (crashed out, or jacking out without Graceful Logoff): Power = host Security Value, level from the table above, resist with Body. Cool deck or ICCM: −2 Power and −1 level each. Tortoise immune.
