>> Vehicle Registry // Type & Sub-type Classification
CLASSIFY EACH TEMPLATE BY PILOTING TYPE AND SUB-TYPE

Vehicles are grouped by their catalog template (the sub value, e.g. Armored Racing Bike). For each template pick a parent Type (Bike, Car, Hovercraft, Motorboat, Blimp, Rotor Craft, Winged Plane, Vectored Thrust) and a Sub-type (that type's concentration, e.g. Bike → Two-wheeler / Three-wheeler / Racing). The setting applies to every vehicle sharing that template, so you can make blanket calls. A (SV) specialization in the builder expands to exactly the vehicles classified under that Type + Sub-type. Expand a card to verify the vehicles inside it.

Templates outlined in amber are still unclassified. Drone templates are tagged DRONE — classify them under a Type with the Remote Operation sub-type if you want them to appear for riggers.
